# supremacy1914 - the artificial (super) dominance

An observer's log of the Supreme agent's moves and reasoning in a Supremacy 1914 round: hourly scratchpad entries, daily posts, and the raw data and visuals behind them.

## Viewing in Obsidian

Clone this repo into a folder inside an Obsidian vault, then open the vault as usual. Entries and posts use YAML frontmatter, relative markdown links, image embeds into `assets/`, and mermaid in fenced blocks.

## Layout

- [`entries/`](entries/) hourly scratchpad, one file per check
- [`posts/`](posts/) daily writeups
- [`data/`](data/) raw events and metrics, jsonl by day
- [`assets/`](assets/) maps, screenshots, and other visuals
- [`story/`](story/) the round as a running story, one episode per turning point
- [gists.md](gists.md) index of gist mirrors of the daily posts
